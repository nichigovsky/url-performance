# URL Performance Analyzer

Проект имитирует анализ производительности веб‑серверов: для списка URL выполняются запросы с случайной задержкой, измеряется время выполнения и формируется агрегированный отчёт.

---

## Возможности

- Параллельная обработка URL-адресов
- Ограничение количества одновременно работающих воркеров (Worker Pool)
- Распределение задач через **Fan-out**
- Сбор результатов через **Fan-in**
- Безопасная синхронизация с использованием `sync.WaitGroup`
- Отсутствие гонок данных (код проходит `-race`)

---

## Используемые технологии

- Go 1.21+
- goroutines
- channels
- sync.WaitGroup
- time, math/rand

## Как работает программа

1. В `main` формируется список из URL-адресов.
2. URL превращаются в задания (`Job`) и отправляются в канал `jobs`.
3. Ограниченное число воркеров (например, 5) параллельно обрабатывают задания.
4. Каждый воркер имитирует HTTP-запрос с помощью `time.Sleep` со случайной задержкой.
5. Результаты обработки отправляются в канал `results`.
6. Все результаты собираются в главной горутине и формируется итоговый отчёт.

## Запуск проекта

### 1. Инициализация модуля

```bash
go mod tidy
```

### 2. Запуск программы

```bash
go run main.go
```

### 3. Проверка на гонки данных

```bash
go run -race main.go
```
